What it covers

Three phases: an automated scan for the mechanical issues, a manual review for what a scan can't judge, and a report ranked by real impact - not just rule violations.

PHASE 01

Automated Accessibility Scan

Missing alt text, insufficient color contrast, ARIA misuse, broken heading structure, and unlabeled form fields - axe-core's WCAG 2.1 AA ruleset, the mechanical checks a machine can verify reliably. This covers roughly 30-50% of real-world WCAG issues, not the full picture.

PHASE 02

Manual Usability Review

Keyboard navigation testing, focus order, meaningful link text (not just present alt text, but whether it actually makes sense), logical reading order for screen readers, and form error handling - the judgment calls a scan can't make.

PHASE 03

Prioritized Report

Issues ranked by real user impact, not just rule violations, with plain-English fixes you can hand straight to whoever builds your site.

How it runs

You submit your domain → I run the scan and review it manually → You get a prioritized report with concrete fixes
